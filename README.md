# Project: Tic Tac Toe | The Odin Project

## Description
This project is a web-based Tic Tac Toe gameboard that is stored inside an array inside of an object to control the flow of the game itself. The purpose of this project is to demonstrate the lessons I learned in [Factory Functions and Module Pattern](https://www.theodinproject.com/lessons/node-path-javascript-factory-functions-and-the-module-pattern) which includes several methodologies in organizing code.
